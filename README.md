# Automation Exercise - Selenium Java

Automation project developed using Selenium WebDriver, Java, TestNG, Maven and the Page Object Model (POM) design pattern.

## Technologies

- Java 17
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- WebDriverManager
- Log4j2
- Allure Report
